# 基金配置工作台

银行客户经理用的基金配置工具：筛选/搜索基金 → 生成「重点基金配置建议」式卡片（费率五项、净值走势+最大回撤、持仓拆解、推荐理由六段式），单一共享口令登录，手机可访问。

## 功能

- 🔐 **登录保护**：单一共享口令（环境变量 `PASSWORD`），内存 token 会话（12h），IP 防爆破（10分钟5次失败锁定）
- 🔍 **基金选择**：输入基金代码 / 关键词搜索（名称/拼音/代码）/ 按 34 种类型筛选
- 📈 **业绩排名**：按近1月/近3月/近1年/近2年/近3年窗口 + 大类（混合/股票/债券/QDII/指数/FOF）看排名
- 🎯 **生成配置建议**：多只基金一键生成组合总览（权益/固收/商品分布 + 核心/卫星/机会定位）+ 单基金卡片
- 🖨 **导出 PDF**：浏览器打印（内置打印样式）

## 本地运行

```bash
npm install
PASSWORD=你的口令 node server.js
# 访问 http://localhost:3005
```

## 部署（Zeabur，推荐）

1. 将本仓库推送到你的 GitHub
2. 打开 https://zeabur.com 微信扫码注册 → 新建项目 → 「从 GitHub 部署」→ 选择本仓库
3. 系统自动识别 `nixpacks.toml` / `.nvmrc` 构建（Node 20）
4. 服务变量配置：`PASSWORD=你的共享口令`
5. 部署完成后获得 `https://<项目名>.zeabur.app` 公网地址，手机可直接访问

> 部署后修改口令：在 Zeabur 服务变量中改 `PASSWORD` 并重新部署即可。

## 数据来源

天天基金网（东方财富）公开数据：基金列表（fundcode_search）、业绩排名（rankhandler）、
基金档案（jbgk/jjjl/gmbd/jjcc 接口）、历史净值（pingzhongdata）。仅作内部参考，不构成投资建议。
